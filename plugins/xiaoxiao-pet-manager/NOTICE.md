# NOTICE / 素材与设计来源

## UI 参考

- **小小桌宠**（yshuang722-spec/xiaoxiao-zhuochong）
  https://github.com/yshuang722-spec/xiaoxiao-zhuochong
  许可：MIT（见本文件下方声明）。
  本插件的管理面板借鉴其控制页的**视觉语言**（暖米色配色 token、左侧栏 +
  角色卡片网格布局、圆角开关与静默按钮样式），为重新实现，未复制其代码；
  其配色常量（`#974c32` / `#faf8f4` / `#efeae2` / `#e5dfd7` 等）作为设计参考值使用。

- **dsh-pet 引擎**（PC2005-cloud/dsh-pet，MIT）是小小桌宠的上游，
  也是本插件管理的桌宠本体（`packs/plugins/dsh-pet`）的来源，一并致谢。
